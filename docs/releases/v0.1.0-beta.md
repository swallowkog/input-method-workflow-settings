# v0.1.0 Beta

第一個公開 Beta 版本，目標是讓少量 macOS 中文輸入法使用者測試核心工作流。

## 下載

請到 GitHub Releases 下載：

```text
Input Method Agent Installer.pkg
```

安裝後會放到：

```text
/Applications/Input Method Agent.app
```

## 主要功能

- 依照目前前景 App 自動切換指定輸入法
- 設定全域預設輸入法，未指定 App 會跟隨全域預設
- App 規則列表、搜尋、篩選與常用規則模板
- Menu Bar 常駐狀態選單
- 暫停自動切換 10 分鐘或 1 小時
- 數字鍵盤修正：在中文輸入法下，右側數字鍵盤仍輸入半形數字
- 權限設定引導：協助使用者開啟「輔助使用」與「輸入監控」
- 本機隱私設計：不記錄、不儲存、不上傳輸入內容

## macOS 權限

完整功能需要：

- 輔助使用：偵測目前 App、切換輸入法、送出修正後的右側數字鍵
- 輸入監控：判斷是否按下右側數字鍵盤

## 已知限制

- 尚未使用 Apple Developer ID 簽署與 notarize。
- 數字鍵盤修正在注音未完成組字時，部分 App 仍可能遇到輸入順序問題。
- 目前以繁體中文介面與台灣注音使用情境為主。

## 測試重點

請優先測試：

1. 不同 App 切換時，輸入法是否正確套用規則。
2. Menu Bar 狀態是否和實際輸入法一致。
3. 暫停 / 恢復自動切換是否可靠。
4. 數字鍵盤在注音狀態下是否輸入半形數字。
5. 權限引導是否清楚。
