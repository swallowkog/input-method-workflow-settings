# v0.1.2 Beta

這個版本主要調整數字鍵盤修正的手感，讓使用者手動按 Enter 完成注音組字後，可以更快接續輸入右側數字鍵盤的半形數字。

## 下載

請到 GitHub Releases 下載：

```text
Input Method Agent Installer.pkg
```

安裝後會放到：

```text
/Applications/Input Method Agent.app
```

## 調整內容

- 加快數字鍵盤修正的快速模式延遲。
- 加快數字鍵盤修正的穩定模式延遲。
- 更新速度提示文字，提醒先按 Enter 完成注音組字，再輸入右側數字鍵。

## 建議使用方式

在注音輸入法下輸入中文後，請先按 Enter 完成組字，再按右側數字鍵盤。這個版本會專注在「完成組字後的數字輸入更快、更順」，不再嘗試自動送出未完成的注音組字。

## 主要功能

- 依照目前前景 App 自動切換指定輸入法。
- App 規則列表、搜尋、篩選與常用規則模板。
- Menu Bar 常駐狀態選單。
- 暫停自動切換 10 分鐘或 1 小時。
- 數字鍵盤修正：在中文輸入法下，右側數字鍵盤仍輸入半形數字。
- 權限設定引導：協助使用者開啟「輔助使用」與「輸入監控」。
- 本機隱私設計：不記錄、不儲存、不上傳輸入內容。

## macOS 權限

完整功能需要：

- 輔助使用：偵測目前 App、切換輸入法、送出修正後的右側數字鍵。
- 輸入監控：判斷是否按下右側數字鍵盤。

## 已知限制

- 尚未使用 Apple Developer ID 簽署與 notarize。
- 如果注音尚未按 Enter 完成組字就直接按右側數字鍵，部分 App 仍可能遇到輸入順序問題。
- 目前以繁體中文介面與台灣注音使用情境為主。
