# 小麥注音與輸入法工作流共存紀錄

更新日期：2026-10-25（Asia/Taipei）。

這份紀錄適用於另外開發、本機使用的「輸入法工作流 2」2.0.1（build `2026.10.1`）與小麥注音 3.1.1（build `2510`）。本次只調整使用者設定，沒有修改產品程式碼、重新編譯或發布新版 App。本儲存庫既有的 Input Method Agent 0.1.2 Beta 原始碼與公開下載不因這份紀錄而更新為工作流 2。

## 問題與對照結果

目標是在中文已出現、尚未按 Enter 確認時，直接用右側數字鍵盤接著輸入半形數字。

使用者確認：

- 小麥注音與原工作流設定同時使用時，中文未確認就按右側數字鍵沒有反應。
- 退出工作流後，小麥可以在中文未確認時直接接半形 `123`。

原工作流同時開啟數字鍵修正，且部分 App 規則仍指向 Apple 注音。目前尚未分別隔離這兩項因素，不能確定干擾只來自其中一項。

## 目前共存設定

小麥處理中文組字與數字，工作流保留依 App 自動切換功能。

1. 關閉工作流的「數字鍵盤修正」。
2. 將需要中文的 App 規則改成小麥注音一般模式；此次調整包含 LINE、備忘錄與 Codex。
3. 原本需要英文的 App 繼續使用 ABC。
4. 保持小麥的「數字鍵盤選字」關閉，重新啟動工作流載入設定。

工作流 2 的相關設定值：

```json
{
  "autoSwitchEnabled": true,
  "numpadCorrectionEnabled": false
}
```

上面只是設定欄位摘要，不是完整設定檔；請優先使用設定介面調整，不要直接覆蓋既有設定。

本次確認可選取的小麥一般模式輸入來源 ID：

```text
org.openvanilla.inputmethod.McBopomofo.McBopomofo.Bopomofo
```

小麥亦有傳統注音模式，設定規則時應以系統實際列出的輸入來源為準。此處使用一般模式。

## 備份與接續

設定修改前已獨立保存主設定及既有備份。若需回復，應先退出工作流、另存當時設定，再還原；還原舊設定也可能重新引入原本的干擾。

接續先確認工作流維持啟用時，中文未確認即可輸入右側 `123`／`123.45`，並在 LINE、備忘錄、Codex 與 ABC App 之間往返測試。若異常再次出現，先確認前景 App、實際選取來源與數字鍵修正狀態，再決定修正；目前方案不需要增加自動 Enter、快速切換 ABC 或按鍵重送。

紀錄不包含私人輸入文字、原始使用者設定、程序識別碼或個人電腦路徑。
