# P0: 改善數字鍵盤修正在注音組字狀態下的穩定性

## 背景

目前已知：在注音尚未按 Enter 完成組字時，部分 App 可能遇到數字輸入順序問題。

## 目標

- 降低注音組字狀態下按右側數字鍵的吃字風險
- 評估「保守模式」或 App 相容性策略
- 維持快速模式的輸入手感

## 建議測試 App

- LINE
- Notes
- Word
- Chrome / Edge 表單
- Finder 重新命名欄位

## 驗收方向

- 在注音組字未按 Enter 的狀態下，按右側數字鍵不應導致數字插入到文字前方
- 快速 / 穩定模式的行為差異清楚
- 若仍有 App 相容性限制，需在 Beta 文件中清楚說明

Priority: P0
