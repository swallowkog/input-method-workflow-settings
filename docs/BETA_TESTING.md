# 0.1.0 Beta 測試指南

這份指南給第一批 macOS 中文輸入法使用者測試「輸入法工作流設定」。目前版本聚焦在核心工作流穩定度，不追求大量功能。

## 測試前準備

1. 從 GitHub Releases 下載 `Input Method Agent Installer.pkg`。
2. 安裝後開啟 `/Applications/Input Method Agent.app`。
3. 依照權限設定引導，開啟 macOS「輔助使用」與「輸入監控」。
4. 回到 App 按「重新檢查」，確認狀態顯示已啟用。

## 建議測試情境

### App 自動切換輸入法

- 設定全域預設輸入法為 `ABC`。
- 替 LINE、備忘錄或 Word 設定為 `繁體注音`。
- 替 VS Code、Terminal、Xcode 或剪輯軟體設定為 `ABC`。
- 來回切換 App，確認輸入法會跟著規則切換。

### Menu Bar 狀態與暫停

- 打開 Menu Bar 選單，確認目前 App、規則與輸入法狀態一致。
- 使用「暫停自動切換 10 分鐘」。
- 確認主視窗與 Menu Bar 都顯示暫停倒數。
- 使用「恢復自動切換」，確認規則重新生效。

### 數字鍵盤修正

- 開啟「數字鍵盤修正」。
- 在注音輸入法下，用右側數字鍵盤輸入 `123.45`。
- 確認輸出是半形 `123.45`，不是全形 `１２３．４５`。
- 測試快速連打，以及在中文組字後立刻輸入數字的情境。

## 已知限制

- 數字鍵盤修正在注音尚未按 Enter 完成組字時，部分 App 仍可能出現輸入順序問題。若遇到此狀況，請切換速度到「穩定」並回報發生在哪個 App。
- 目前安裝包尚未使用 Apple Developer ID 簽署與 notarize，公開測試時 macOS 可能顯示安全性提示。
- App 需要「輔助使用」與「輸入監控」權限。這些權限只用於偵測目前 App、切換輸入法，以及處理右側數字鍵盤，不會記錄或上傳輸入內容。
