# Screenshots

建議在 `0.1.0 Beta` Release 後補上正式截圖，放到 `docs/screenshots/`，再嵌入 README。

## 建議截圖清單

1. 主設定視窗：顯示全域預設、App 規則列表、數字鍵盤修正與權限狀態。
2. 權限設定引導：顯示四步驟引導與拖入權限清單動畫。
3. Menu Bar 選單：顯示目前 App、輸入法、暫停與快速開關。
4. 數字鍵盤修正：顯示隱私說明、快速 / 穩定選項與測試區。

## 建議檔名

```text
docs/screenshots/settings-window.png
docs/screenshots/permission-guide.png
docs/screenshots/menu-bar.png
docs/screenshots/numpad-correction.png
```

補上截圖後，可在 README 加入：

```markdown
## 截圖

![設定視窗](docs/screenshots/settings-window.png)
![權限設定引導](docs/screenshots/permission-guide.png)
![Menu Bar 選單](docs/screenshots/menu-bar.png)
```
